# Báo Cáo Đối Soát Giao Diện & Dữ Liệu Thực Tế Teknova 2026

Gói tài liệu bàn giao kỹ thuật & đối soát trực quan giữa bản Dev Demo và bản Thiết kế tham chiếu, căn cứ theo **Hồ Sơ Năng Lực Teknova 2026**.

## Cấu trúc thư mục:
- `index.html` (hoặc `BAO_CAO_TEKNOVA.html`): Báo cáo HTML trực quan, có sidebar menu và click phóng to ảnh (Lightbox). Mở trực tiếp trên bất kỳ trình duyệt nào.
- `visual_comparison/`: Chứa toàn bộ 24 ảnh chụp đối soát trực quan 1-1 cho 8 block trang chủ và 4 trang con.
- `BAO_CAO_DOI_SOAT_TEKNOVA_2026.pdf`: Bản báo cáo định dạng PDF hoàn chỉnh.

## Hướng dẫn sử dụng:
1. Mở trực tiếp file `index.html` trên trình duyệt (Chrome, Edge, Firefox, Safari).
2. Khi push lên GitHub, có thể kích hoạt **GitHub Pages** (Settings -> Pages -> Branch main -> Save) để xem online ngay lập tức qua link web.
